# 历史文档归档

本目录保存已经完成、被替代或不再作为当前执行入口的资料。归档不是删除：这些文档仍可用于追溯设计决策、验收口径和版本演进，但不应直接当作当前实施计划。

| 目录 | 内容 |
|---|---|
| [`phases/`](./phases/) | Phase 1–8 的阶段计划、需求和研究记录 |
| [`planning/`](./planning/) | 旧版路线图、迁移计划和剩余工作计划 |
| [`ui/`](./ui/) | 已归档的 UI 重构提示词或一次性工作材料 |
| [`packages/`](./packages/) | 历史工具包或交付压缩包 |

需要恢复某项历史任务时，应先对照当前代码和最新版本计划重新验收，再把新的执行计划放入对应的 `releases/vX.Y.Z/`。
