## 5. 故障注入覆盖（测试证据）

- sidecar 级：安装版 smoke 真实进程启停、命令取消/进程树清理；
- 审批级：过期、参数篡改、token 重放、双消费、unknown 人工处置；
- 命令级：超时、取消、输出洪泛、编码错误、非白名单/控制符拒绝；
- SQL 级：慢查询超时、写语句双层拒绝、连接失败；
- HTTP 级：重定向/私网/慢端点/坏 Schema/secret 通道缺失；
- 崩溃级：unknown execution 不自动重放、重启续跑副作用单次（B1/B2/B5 测试）。
