## 1. 交付内容

### 1.1 Endpoint profile（`core/http_profiles.py` + `api/routes_http_profiles.py`）

- `http_endpoint_profiles`（0023 建表 + additive 0025 增加 `allow_insecure_local` /
  `allow_private_network` 显式 opt-in，默认拒绝私网/环回）；
- 配置校验复用 MCP 防护语义：scheme/端口/凭据/fragment、敏感头（Authorization/
  Cookie 等）禁止、secret 引用格式强制（`secret://os-keyring/http/<name>/<slot>`）、
  方法仅 GET/HEAD/POST；
- CRUD API `/http-profiles`（flag `PA_AGENT_HTTP_WORKFLOW_ENABLED` 门禁）：
  只读写非敏感元数据与引用。

### 1.2 可信执行器（`core/http_workflow.py`）

- 模型只能引用已启用 profile（不存在/禁用 → 失败关闭）；URL 由 profile 构造；
- **复用 MCP DNS 钉住三件套**（`mcp/client.py`）：解析一次、全部结果必须为全局
  地址（或显式允许私网）、连接只允许已验证地址集、禁止 Unix socket；
- `trust_env=False`（不跟随环境代理）、`follow_redirects=False`、TLS 校验保留；
- POST 必须幂等键（executor 强制）；请求体按 profile Schema 校验；有界重试
  （GET/HEAD 连接错误/5xx 可重试，最多 3 次）；超时/取消协作；
- 响应：状态码、headers（敏感头剔除）、body（有界截断 + JSON 解析）、
  `schema_valid`（按 profile 固定响应 Schema）；secret 只经 keyring 通道注入
  请求头，响应与日志脱敏。

### 1.3 验证器与注册（`routes_agent_runs.py`）

- HTTP flag 开启时注册 `call_allowlisted_api`（`network.fetch` 授予）；
- `ApiResultVerifier` 固定注入（状态码 200-299、attempts ≤3、新增
  `reject_schema_invalid` 检查——executor 的 `schema_valid=False` 即失败关闭）。

### 1.4 keyring 通道（Rust + Python）

- `credentials.rs`：`http.<name>.<slot>` 账户与 `secret://os-keyring/http/...`
  引用（别名/槽位校验 + 单元测试）；
- `lib.rs`：`http-profile-secret-index.json`（≤32 条）、
  `collect_http_profile_secrets_for_sidecar()`（Zeroizing）、Tauri commands
  `set/clear/http_profile_secret_status`、sidecar 启动注入
  `PA_HTTP_PROFILES_SECRETS_JSON`（仅 `http_workflow_enabled` 时）；
- Python 侧 `load_process_http_secret_resolver()` 一次性消费并清除环境变量，
  畸形条目整体 fail closed。

### 1.5 UI（Settings 卡片 06「HTTP 端点」）

- profile 列表（目标/方法/超时/大小/启用状态）、创建/编辑/删除/启用切换；
- secret 槽位输入：桌面壳写入 OS keyring（明文不经 Vue 持久化），
  非桌面环境提示不可用。

## 3. 已知边界

- loopback/私网目标需显式 opt-in（`allow_insecure_local` + `allow_private_network`），
  测试服务按此配置；
- secret 明文在开发环境需注入 `PA_HTTP_PROFILES_SECRETS_JSON` 通道或测试
  resolver；生产由桌面壳 keyring 收集（Rust 通道已实现）；
- `ApiResultVerifier.reject_schema_invalid` 为 additive 参数（默认 False，
  不影响既有调用方）。
