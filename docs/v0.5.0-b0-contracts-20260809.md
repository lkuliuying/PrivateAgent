## 2. 五类工具冻结契约

字段含义与约束与 `agents/tools.py` 的 `ToolSpec` 一致；`flag_env` 为控制可见性的
独立开关环境变量。摘要列为本文档日期冻结值，改动必须同步更新
`tests/test_workflow_contracts.py::test_frozen_schema_hashes_are_stable`。

### 2.1 `propose_patch`（既有只读工具，一并冻结）

| 字段 | 值 |
|---|---|
| version / risk / idempotency | `1.0.0` / `safe` / `idempotent` |
| required_capabilities | `filesystem.read` |
| 必需验证器 | `file_diff` |
| flag | `PA_AGENT_RUN_READ_ONLY_TOOLS_ENABLED`（既有） |
| timeout / max_output | 20s / 512 KiB |

输入：`project_id`、`rel_path`(≤2048)、`new_content`(≤500000)、`create`。
输出：`project_id`、`rel_path`、`diff`(≤200020)、`old_sha256`、`new_sha256`、
`creates_file`、`changed`、`truncated`。

### 2.2 `apply_patch_to_workspace`（B1 迁入 versioned registry）

| 字段 | 值 |
|---|---|
| version / risk / idempotency | `1.0.0` / `confirm` / `non_idempotent` |
| required_capabilities | `filesystem.read` + `filesystem.write` |
| 必需验证器 | `file_diff` |
| flag | `PA_AGENT_PATCH_WORKFLOW_ENABLED` |
| timeout / max_input / max_output | 30s / 600 KiB / 512 KiB |

输入：`project_id`、`rel_path`(≤2048)、`new_content`(≤500000)、
`expected_old_sha256`(强制 64 位十六进制)、`create`。
输出：`project_id`、`rel_path`、`old_sha256`、`new_sha256`、`size_bytes`、
`diff`、`truncated`、`verified`（写入后回读磁盘核对 new_sha256 的结果，B1 必须实现）。

相对 legacy 收紧：rel_path 限长、old SHA 格式校验、输出强制回读验证标志。

### 2.3 `run_whitelisted_command`（B2 迁入 versioned registry）

| 字段 | 值 |
|---|---|
| version / risk / idempotency | `1.0.0` / `confirm` / `non_idempotent` |
| required_capabilities | `process.execute` + `filesystem.read` |
| 必需验证器 | `shell` + `code_command`（组合） |
| flag | `PA_AGENT_COMMAND_WORKFLOW_ENABLED` |
| timeout / max_input / max_output | 120s / 128 KiB / 512 KiB |

输入：`project_id`、`command`（**只接受参数数组**，1..64 项，每项 ≤4096）、
`timeout`(1..120s)。
输出：`project_id`、`args`、`cwd`、`returncode`、`stdout`/`stderr`/`output`(各 ≤512KiB)、
`truncated`、`succeeded`，可扩展 `cancelled` / `processes_remaining`（B2 进程树清理证据）；
B2 additive：可选 `profile`（匹配的项目 command profile 名称，未匹配时省略）。

相对 legacy 收紧：拒绝字符串命令（不经 shell），拒绝 shell 控制符。

### 2.4 `call_allowlisted_api`（B3 接入）

| 字段 | 值 |
|---|---|
| version / risk / idempotency | `1.0.0` / `confirm` / `idempotent` |
| required_capabilities | `network.fetch` |
| 必需验证器 | `api` |
| flag | `PA_AGENT_HTTP_WORKFLOW_ENABLED` |
| timeout / max_input / max_output | 60s / 256 KiB / 1 MiB |

输入：`profile_id`、`method`(仅 GET/HEAD/POST)、`path`(profile 前缀内，≤4096)、
`query_params`(≤64 项)、`body`(对象，按 profile Schema)、`idempotency_key`
(POST 必填，契约级校验)。
输出：`profile_id`、`method`、`path`、`status_code`、`headers`(脱敏)、`body`、
`truncated`、`schema_valid`、`elapsed_ms`、`attempts`、`idempotency_replayed`。

### 2.5 `query_readonly_sql`（B4 接入）

| 字段 | 值 |
|---|---|
| version / risk / idempotency | `1.0.0` / `confirm` / `idempotent` |
| required_capabilities | `database.query` |
| 必需验证器 | `database` |
| flag | `PA_AGENT_SQL_READONLY_WORKFLOW_ENABLED` |
| timeout / max_input / max_output | 30s / 128 KiB / 1 MiB |

输入：`profile_id`、`query`(≤65536，单条只读)、`params`(≤256)、
`max_rows`(1..10000)、`timeout_ms`(100..30000)。
输出：`profile_id`、`columns`、`rows`(限长脱敏)、`row_count`、`truncated`、
`elapsed_ms`、`read_only_confirmed`、`message`。

### 2.6 幂等策略

- `apply_patch_to_workspace` / `run_whitelisted_command`：`non_idempotent`，
  崩溃后的 unknown execution 不自动重放，需要人工处置；
- `propose_patch` / `call_allowlisted_api` / `query_readonly_sql`：`idempotent`，
  GET/HEAD 可重试，POST 必须携带幂等键。

## 3. Feature Flag 与 /capabilities

### 3.1 新增开关（全部默认关闭）

```text
PA_AGENT_PATCH_WORKFLOW_ENABLED        → apply_patch_to_workspace
PA_AGENT_COMMAND_WORKFLOW_ENABLED      → run_whitelisted_command
PA_AGENT_HTTP_WORKFLOW_ENABLED         → call_allowlisted_api
PA_AGENT_SQL_READONLY_WORKFLOW_ENABLED → query_readonly_sql
```

- 一个 flag 只映射一类工作流；**不存在**同时开启多类工作流的总开关（测试固化）。
- 开启规则（承接主计划 §7.2）：B1 只允许内部构建开启 Patch/命令；B2 才允许 HTTP/SQL；
  未配置 profile / 授权项目时对应工具不注册；单开关关闭无需数据库 downgrade。
- `config.py` 新增字段名与 env 一一对应，字段默认 `False`（测试固化）。

### 3.2 `/capabilities` additive 扩展

`RuntimeCapabilities` 新增四个字段（默认 `false`，既有字段不变）：

```json
{
  "chat_execution_mode": "agent_runtime|legacy",
  "legacy_tool_planner_enabled": true,
  "agent_read_only_tools_enabled": false,
  "rag_chat_runtime_enabled": false,
  "patch_workflow_enabled": false,
  "command_workflow_enabled": false,
  "http_workflow_enabled": false,
  "sql_readonly_workflow_enabled": false
}
```

桌面端 `apps/desktop/src/api/runtime.ts` 同步扩展；旧后端不返回新字段时前端按
字段缺省处理（新增字段均为可选消费，不阻断既有协商逻辑）。

## 4. 威胁清单（B1–B4 验收输入）

每类工作流按 STRIDE 思路列出必须拒绝/必须验证的威胁；对应实现验收测试在 B1–B4 落地。

### 4.1 Patch（B1）

| 威胁 | 必须拒绝/验证 |
|---|---|
| 绝对路径 / `..` 穿越 / UNC 路径 | 只允许授权项目根内相对路径；`resolve_within` 双重校验 |
| 符号链接 / 目录联接 / Windows 重解析点越界 | 写入前解析真实路径仍在根内；拒绝链接目标越界 |
| TOCTOU（校验后路径被替换） | 同目录临时文件 + 原子替换；写前重校验路径 |
| 过期 Diff 应用 | 审批绑定 `project_id + rel_path + old_sha256 + new_sha256 + tool_version`；写前复核 old SHA |
| 审批 token 重放 / 参数篡改 / 双消费 | 一次性 token、参数哈希绑定（既有 approvals 复用） |
| 写入后不一致（磁盘/回读不符） | 回读磁盘核对 new SHA，不一致失败关闭 |
| 截断预览直接应用 | 预览被截断时拒绝应用，必须重新生成完整分块 Diff |
| 崩溃后未知写入重放 | `non_idempotent` + execution unknown 人工处置（既有 executions 复用） |
| 目录删除 / 批量删除 / 二进制 patch | v0.5.0 不支持，schema 与实现拒绝 |

### 4.2 命令（B2）

| 威胁 | 必须拒绝/验证 |
|---|---|
| shell 控制符（`&&` `||` `;` `|` `>` `>>` `<`） | 参数数组逐项检查，字符串命令直接拒绝 |
| 非白名单命令 / 子命令 / 参数模式 | 复用并收紧 `project_command_profiles`；模型不能扩大白名单 |
| 任意 cwd | 固定为授权项目根目录或 profile 声明子目录 |
| 环境变量泄露（代理/凭据/无关继承） | 固定 allowlist env，清除代理、凭据与无关变量 |
| 超时 / 取消后子进程残留 | Windows 进程组/Job Object 或等价方案清理进程树；取消后验证无子进程、端口、临时锁 |
| 输出洪泛 / 无限增长 | stdout/stderr 流式显示、持久化有界、截断标记 |
| secret 进入输出 | 输出脱敏（sensitive keys + 文本模式） |
| 编码损坏 | 非 UTF-8 输出安全替换 |
| 重试重复执行未知状态命令 | `non_idempotent`，unknown 不自动重跑 |

### 4.3 HTTP/API（B3）

| 威胁 | 必须拒绝/验证 |
|---|---|
| 任意 URL / 任意 Host | 模型只能引用已启用 profile；URL 由 profile 构造 |
| SSRF：私网 / 环回 / 链路本地 / 云元数据 | 复用 MCP `mcp/validation.py` + `mcp/client.py` 的 DNS 解析全量校验与钉住 |
| DNS rebinding 换址 | 连接目标固定为已验证地址集，重定向默认禁用 |
| 降级 HTTP / 非 HTTPS | 默认仅 HTTPS；仅 loopback 允许显式 http |
| 环境代理注入 | `trust_env=False`，不跟随系统代理 |
| 非白名单方法 | schema 只允许 GET/HEAD/POST；PUT/PATCH/DELETE 不开放 |
| POST 无幂等键重放 | 写方法必须携带幂等键（契约校验 + executor 校验） |
| 响应超限 / 错误 Schema / 超重试 | 状态码、Schema、大小、重试次数验证后才进入模型上下文 |
| secret 进入模型参数/Vue/DB/日志 | keyring 引用注入；metadata-only 审计 |
| 禁用/删除 profile 后继续调用 | 每次执行实时校验 profile 存在且 enabled |

### 4.4 只读 SQL（B4）

| 威胁 | 必须拒绝/验证 |
|---|---|
| DDL / DML / 存储过程 / 临时表 / 锁 / `FOR UPDATE` | 可靠解析（非字符串前缀）+ 数据库只读事务双重限制 |
| 多语句注入 | 单语句强制 |
| 任意 DSN / 凭据 | 只能引用已启用 profile；密码仅 OS keyring |
| 慢查询 / 悬挂连接 | 超时可取消，无悬挂连接 |
| 结果洪泛 | 最大行数 + 最大字节数 + 截断标记 |
| 大字段 / 秘密列进 UI | 默认隐藏疑似秘密列，UI 仅显示有界表格预览 |
| 应用层绕过只读策略 | 数据库账号即使配置错误也不能绕过只读事务 |
| 主库被工作流影响 | 独立连接；关闭 SQL flag 不影响主库 |

## 5. 数据库决策（B0）

### 5.1 0014–0016 复用确认

`tool_approvals`（0014）、`agent_run_checkpoints`（0015）、`agent_tool_executions`

### 5.2 additive 迁移 0023（已创建）

决策：**需要**。HTTP/SQL 工作流必须持久化非敏感 profile，新增：

- `http_endpoint_profiles`：`name`(唯一)、`scheme`(默认 https)、`host`、`port`、
  `path_prefix`、`allowed_methods_json`、`request_schema_json`、`response_schema_json`、
  `max_request_bytes`(默认 64KiB)、`max_response_bytes`(默认 1MiB)、`timeout_ms`(默认 30s)、
  `headers_json`(仅非敏感固定头)、`secret_refs_json`(header → keyring 引用)、
  `retry_policy_json`(非敏感)、`enabled`(默认 0)、`version`(乐观锁)、时间戳。
- `sql_readonly_profiles`：`name`(唯一)、`dialect`、`host`、`port`、`database`、
  `username`(元数据)、`password_secret_ref`(keyring 引用)、`connect_args_json`(非敏感)、
  `max_rows`(默认 1000)、`max_bytes`(默认 1MiB)、`timeout_ms`(默认 30s)、
  `enabled`(默认 0)、`version`(乐观锁)、时间戳。

约束：两表不允许保存明文 secret；downgrade 仅删两表（additive 回退）；
已加入 `core/backup.py` 的 `BACKUP_TABLES` 与备份/恢复/诊断数据计数范围。

## 6. Secret 生命周期与备份策略

### 6.1 生命周期

1. 明文 API key / 数据库密码只进入 **OS keyring** 与当前 sidecar 内存；
2. 数据库只保存 keyring 引用（`secret_refs_json` / `password_secret_ref`）；
3. 模型参数、Vue 状态、执行结果、日志与发布证据均不得出现明文；
4. 备份导出时：`headers_json` / `connect_args_json` 保留键名、清空值；
   keyring 引用按标识保留（还原后在新机器上不可用，符合"不可用引用说明"）。

### 6.2 删除与禁用

- 删除或禁用 profile 后，对应工具不得继续被调用（B3/B4 每次执行实时校验）；
- 密钥轮换 = 更新 keyring 条目 + 递增 profile `version`。

### 6.3 备份清理实现

`core/backup.py::_dump_table` 新增分支（测试 `test_backup_sanitizes_workflow_profile_secrets`）：

- `http_endpoint_profiles.headers_json` → `{name: ""}`；
- `http_endpoint_profiles.secret_refs_json` → 原样（标识）；
- `sql_readonly_profiles.connect_args_json` → `{name: ""}`；
- `sql_readonly_profiles.password_secret_ref` → 原样（标识）。
