## 本轮完成

### 验收遗留（alpha.1 后用户反馈）
1. **Python "协程未等待" 运行时警告**：`src/personal_assistant/agents/runtime.py` 的
   `_await_with_cancellation` 原先在 `ensure_future` 之前执行 `raise_if_cancelled()`——
   取消窗口内已创建的 `complete` 协程无人接管，GC 时触发
   `RuntimeWarning: coroutine ... was never awaited`。
   修复：协程先调度（`ensure_future`）再检查取消，任何路径下协程都进入任务被 await/cancel。
   验证：`pytest -W always::RuntimeWarning` 全量 637 通过、零 RuntimeWarning。
2. **NavRailV2 4 处局部 RGBA 字面量**：收敛为组件令牌
   `--pa-rail-brand-border` / `--pa-rail-brand-bg` / `--pa-rail-active-border` /
   `--pa-rail-icon-bg` / `--pa-rail-running-glow`（legacy NavRail 同步收敛）。

### alpha.2 契约切换：默认新 UI
- `DEFAULT_UI_V2 = true`：默认进入 v2 壳；`?ui=v1` / `pa_ui_v2=0` 回退兼容壳；
- E2E 适配：
  - legacy 动画模块（`chat.ts`/`agent.ts`，仅 v1 壳挂载）回归测试固定 `?ui=v1`；
  - 共享行为测试改为壳无关（nav testid 等待、`heading().first()`、hover 测量前先 `scrollIntoViewIfNeeded`）；
  - 结果：Playwright 25/25 通过（默认壳 = v2）。
