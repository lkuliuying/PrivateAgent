## 1. 本次新增

- **A5 契约冻结**：`docs/v0.3.0-public-contracts.md` 冻结 capabilities/SSE/run 状态/事件/审批/RAG 引用/摘要元数据/telemetry 标签/错误码词汇；`tests/test_public_contracts.py`（12 项）以测试固化，破坏性变更必须先更新文档与相关 E2E。
- **A3 真实模型审批缺陷修复（重要）**：
  - 根因：`get_agent_tool_bundle` 在 RAG 开启时无条件注入 RAG 引用验证器（带 strict JSON `output_schema`），普通聊天也被强制 JSON 输出；qwen2.5:14b 在带 `format` 的请求下抑制工具调用，CONFIRM 工具审批在真实模型中永远无法触发（此前 M0 演练 3 次均 `approval_not_triggered`）。
  - 修复：RAG 引用验证器只对 `knowledge_base=true` 注入（chat 与 `/agent-runs` 两路径一致）；新增 additive 迁移 `0022` 持久化 `agent_runs.knowledge_base`，审批恢复路径按同一持久化事实判断。
  - 验证：真实模型端到端审批（`waiting_approval → approve → completed`）事件链完整；新增回归测试 `test_plain_chat_does_not_inject_rag_verifier_but_rag_chat_does`。
- **A0 工具链可信度修复**：
  - `m0_agent_run_driver.py`：取消分支接受 `created` 状态（create 响应即为 created），修复取消样本从未触发的问题；
  - `m0_gate_runner.py`：审批只在审批提示词所在 run 上尝试一次（此前首轮即吞掉普通 run 记录）；审批未触发时按普通 run 记录并附 `approval_note`；新增 `POST /files/authorize` 预授权（read_file 为 CONFIRM 工具需要授权路径）。
- **A4 安装版 smoke**：新增 `scripts/summary_worker_smoke.py`，对构建版 sidecar 做摘要 worker 端到端验收（本地模型生成、幂等、原始消息保留、telemetry 无正文、优雅停机、无残留）。

## 4. 已知问题与回退

- 旧 M0 runner 的 `observation_days>=7`、`valid_completed_runs>=100` 门槛按新计划不再作为阻塞标准（开发期基线 20 run 即达标），`gate_pass=false` 仅由这两项引起。
- 回退：关闭 `PA_CHAT_AGENT_RUNTIME_ENABLED` 回到 legacy 普通聊天；RAG 聊天关闭 `PA_AGENT_RAG_TOOLS_ENABLED` 走兼容路径；关闭摘要 worker 不影响聊天主链。全部不需要数据库 downgrade。
- 迁移 `0022` 为 additive，旧应用可忽略新列。
