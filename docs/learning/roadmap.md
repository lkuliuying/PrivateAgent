# 四周日程

每天以 1–2 小时为上限。先复述昨天的调用链，再阅读当天的入口，观察测试断言，最后填写[学习记录](workbook.md)。主链路能解释后，再展开辅助函数；遇到没有读过的依赖，先记录它的契约和状态归属。

模块名对应[实现卡](modules.md)，实验编号对应[隔离实验](labs.md)。实验可以拆成“阅读断言”和“执行套件”两次完成。D07、D14、D21 集中运行本周未执行的套件；不会因没有真实 API Key 而阻塞学习。

## 第一周：贯通一次任务

### D01 产品边界与整体地图

- **阅读：**[项目 README](../../README.md)和[架构说明](architecture.md)。定位共享 `AgentRuntime`、本机 `Runtime`、桌面 `CodingThreadWorkspace`，暂不展开全部实现。
- **实验：**阅读 [L01](labs.md#l01-agent-循环) 中无工具完成和工具失败回填的两个测试。用纸笔列出模型、工具、事件三个参与者。
- **产出：**重画进程图，标注内存、SQLite、工作区文件、系统凭据库和外部供应商。
- **自测：**“本机 Agent”的哪些数据可能发送到供应商？共享核心为什么不直接读文件？

### D02 输入、创建运行与事件投影

- **阅读：**[M01](modules.md#m01-工作台与事件投影)，按 `CodingThreadWorkspace.send → useRunStream.startRun → requestPrivateRuntime → runProjector` 阅读。再查看 `CodingComposer` 与 `codingWorkspaceStore` 的职责。
- **实验：**[L03](labs.md#l03-前端创建去重与事件续读)，比较运行创建成功、响应丢失、事件重复和过期连接的处理。
- **产出：**画“输入→请求→快照→事件→界面”图，标记 draft 何时确认、哪些状态由快照纠正。
- **自测：**为什么前端断开流不等于后台任务取消？组件、模块级 store、composable 分别负责什么？

### D03 Python sidecar、私有 stdio 与本机 API

- **阅读：**[M02](modules.md#m02-桌面启动与私有-ipc)与[M03](modules.md#m03-api-与身份作用域)，按 `startLocalExecutor → requestPrivateRuntime → local_executor_request → IPC transport → create_app` 阅读。
- **实验：**[L04](labs.md#l04-存储事务与私有-ipc)，观察请求 ID、流帧、取消订阅和请求路径校验。
- **产出：**补全启动顺序图：Rust 宿主、Python、ASGI 分发、前端连接。标记 stdout 协议与 stderr 日志的边界。
- **自测：**默认桌面是否需要开放 TCP 端口？为什么 IPC 仍要校验路径、长度和身份作用域？

### D04 核心实体、事务与事件持久化

- **阅读：**[M04](modules.md#m04-sqlite-与历史持久化)，重点看 `Store` 初始化、迁移、`emit`，以及 runs、events、sessions 和工作区引用的关联。
- **实验：**[L04](labs.md#l04-存储事务与私有-ipc)，比较事件与状态同事务、迁移失败回滚、内容摘要校验。
- **产出：**重画逻辑实体图；另列“内存对象／数据库 JSON／内容文件／密钥”的保存位置。不要把逻辑关联全部画成物理外键。
- **自测：**如果写入事件成功而更新运行状态失败，重启后会怎样？当前实现如何避免这一不一致？

### D05 模型配置、统一消息与适配器

- **阅读：**[M05](modules.md#m05-模型协议与适配)，顺着 `ConfiguredModels → ModelGateway → 具体 adapter` 看消息、工具参数、流事件和结束原因的转换。
- **实验：**[L02](labs.md#l02-模型契约与原生状态)，先观察共享消息规范，再选择 Responses 或 Claude 适配器精读一个成功与失败用例。
- **产出：**写一张消息转换表：内部表示、供应商表示、流事件、工具调用 ID、原生状态适用条件。
- **自测：**为什么“支持某供应商”不足以证明所有模型都可续接同一个原生状态？

### D06 一次完整 Agent 循环

- **阅读：**[M06](modules.md#m06-agent-循环与本机适配)，按 `Runtime._execute → LocalRunAdapter → AgentRuntime._drive` 看模型调用、工具分批、结果回填、预算和取消。
- **实验：**执行 [L01](labs.md#l01-agent-循环)。至少观察多个工具后回到模型，以及预算不足时拒绝不完整工具批次。
- **产出：**手写 Agent 循环伪代码，标记版本检查、审批暂停、取消、工具异常和最终验证。
- **自测：**模型、运行时、执行层分别能决定什么？为什么并行只适用于满足契约的只读调用？

### D07 第一周验收

- **复盘：**脱离源码，从点击发送讲到最终事件持久化，包含一次工具调用、一次失败回填和一个终止条件。
- **补实验：**运行本周未完成的 `shared-models`、`direct-models`、`parallel`；前端按 L03 执行。时间不足时保留明确的待运行项。
- **交付：**进程图、时序图、实体图、M01–M06 模块卡和 10 分钟录音或书面讲稿。
- **达标：**能指出每个跨层调用的输入输出；能区分快照、事件和上下文；能解释两种异常路径。只记住类名需要回到对应天重读。

## 第二周：理解执行为什么可控

- **产出：**绘制“原始输入／派生约束／计划／追加指令”的来源与版本表。
- **自测：**当前需求解释有哪些确定性规则的局限？模型更新计划能否自行解除用户限制？

### D09 工具注册、可见性与发现

- **阅读：**[M09](modules.md#m09-工具契约与按需发现)，按 `ToolSpec → ToolRegistry → ToolCatalog → LocalRunAdapter` 看 schema、工具列表、发现结果和执行派发。
- **实验：**[L06](labs.md#l06-工具发现与有界并行)，观察未注册工具不被派发，以及读调用和写调用分批。
- **产出：**绘制工具从“实现存在”到“本次任务可调用”的条件表。
- **自测：**为什么工具注册、模型可见、参数有效、审批通过、实际执行是五个不同结论？

### D10 文件版本、搜索分页与补丁

- **阅读：**[M10](modules.md#m10-文件搜索与补丁)，重点看 `Repository` 的读版本、搜索游标和 `PatchService` 的预览、提交、journal 与回滚。
- **实验：**[L07](labs.md#l07-补丁版本冲突与局部失败)，观察预览后外部修改、多文件第二次写入失败和重复请求。
- **产出：**画出预览摘要、授权、版本复核、写入和恢复之间的关系，标注每个可能失效的时点。
- **自测：**为什么审批后仍然要复核文件？多文件修改为什么不能直接等同于数据库事务？

### D11 审批、路径与 Windows 沙箱

- **阅读：**[M11](modules.md#m11-权限与系统沙箱)，查看 policy、授权作用域、路径保护和 AppContainer 配置；对照敏感路径测试。
- **实验：**[L08](labs.md#l08-权限命令与进程生命周期)，选择审批拒绝、敏感路径保护两个用例；原生验证按前置条件执行。
- **产出：**列出批准绑定的工作区、动作、版本和限制；区分程序策略检查与 OS 进程权限。
- **自测：**`full_access` 代表什么？它是否等于管理员权限、任意绕过审批或任意网络访问？

### D12 命令宿主、输出与进程回收

- **阅读：**[M12](modules.md#m12-命令宿主与持续执行)，按 `ExecutionSessions → ExecHostClient → exec-host` 看创建、poll、stdin、timeout、cancel 与 cleanup。
- **实验：**[L08](labs.md#l08-权限命令与进程生命周期)，比较正常退出、取消、服务中断和未知结果。记录哪个结果没有 exit code。
- **产出：**绘制命令 session 生命周期；标记输出游标、运行身份、进程树和遗留状态。
- **自测：**停止读取输出、发送 stdin、取消命令和结束 Agent 运行有什么区别？

### D13 追加指令、迟到响应与连接恢复

- **阅读：**回到[M08](modules.md#m08-计划与运行控制)、[M15](modules.md#m15-任务恢复)和 `useRunStream`，看 `RunControls`、goal version、generation 与 after sequence。
- **实验：**[L11](labs.md#l11-任务恢复与未知副作用)的迟到响应用例，加上 L03 的重连用例。
- **产出：**画“运行中→暂停／追加要求→继续”的状态图；另画浏览器流连接的状态图。
- **自测：**追加指令后，旧模型响应为什么不能继续写计划或文件？前端 generation 与目标版本保护的边界是否相同？

### D14 第二周验收

- **场景：**依次解释审批被拒、预览后用户修改文件、命令取消；对每个场景说明磁盘、授权、事件和运行状态。
- **补实验：**按需要运行 `repository`、`security`、`orchestration`，不重复已完成且无新问题的套件。
- **交付：**M07–M12 模块卡、补丁事务边界图、审批绑定表、进程与运行两个状态图。

- **自测：**“AI 写了代码，你做了什么？”能否用实际决策和验证回答，而不依赖模糊职责？

### D28 模拟面试与补漏

- **演练：**按[模拟面试流程](interview.md#模拟面试与评分)完成 90 秒介绍、10 分钟展开、20 分钟追问。模拟面试可自己录音或请同伴提问。
- **评分：**依据六个维度评分，记录回答中无法定位源码或证据的句子。
- **产出：**最终架构图、时序图、实体图、20 张模块卡、3 个案例、介绍与追问提纲，以及待补问题清单。
- **达标：**总分达到 14/18，且没有把历史架构、合成回归或他人实现描述为当前功能、真实生产验收或个人贡献。未达标的主题回到对应模块与实验，不靠背答案补齐。
