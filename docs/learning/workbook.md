## 图的填写模板

- **进程图：**标明 Vue、Rust/Tauri、Python、SQLite、系统凭据库、工作区和供应商；箭头写协议或函数边界。
- **任务时序图：**输入、请求 ID、运行快照、上下文、模型、工具、审批、结果回填、验证、终态事件。
- **实体图：**project、workspace、session、run、event、step、context、draft、attachment；标明逻辑关联与真正外键的区别。
- **控制状态图：**至少包含 running、waiting approval、paused、取消和终态；目标版本变化与连接 generation 单独标注。
- **上下文图：**必要规则／限制、计划、调用组、可选记忆、摘要、原文引用及完整请求预算。
