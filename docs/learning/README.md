# PrivateAgent 学习与面试准备

这套材料用于系统理解当前本机桌面 Agent，并准备 AI 应用与 Agent 开发岗位面试。按四周、每天 1–2 小时安排，适合熟悉基础语法、需要加强调用链理解、有 AI 辅助开发经历的学习者。

完成后的目标是：解释一次任务的完整生命周期，讲清主要模块的实现和失败处理，准备 90 秒介绍、10 分钟技术展开，以及三个由个人实际经历支持的案例。

## 从哪里开始

1. 阅读[架构与任务调用链](architecture.md)，先画出进程和核心实体。
2. 按[四周日程](roadmap.md)完成 D01；每天只精读当日指定入口。
3. 用[模块实现卡](modules.md)核对职责、输入输出、状态和设计取舍。
4. 用[隔离实验手册](labs.md)观察成功和失败路径，记录实际结果。
5. 在[学习记录模板](workbook.md)中记录掌握情况、证据和未解决问题。
6. 第四周用[面试手册](interview.md)组织回答，并完成模拟面试。

## 学习基线

源码基线为 2026-10-06 的本地提交 `87a8331`。这是阅读版本，测试结果需按每次实际执行记录。后续代码改变时，先重新确认对应符号、契约和测试断言。

当前产品是 Vue 3、TypeScript、Tauri 2、Python 本机执行器、共享 AgentRuntime 与 SQLite 组成的 API Key 桌面工作台。旧服务器、平台账号、MySQL/Alembic 和 RAG 属于历史架构。

[项目状态记忆](../project-state.md)保留 2026-09-19 及更早的快照，其中插件占位、早期 MCP 范围等描述有明确时间边界。学习当前功能时，与[项目 README](../../README.md)、现有源码和专题说明交叉核对。该学习材料不改写历史状态记忆。

## 每天如何学习

| 环节 | 时间 | 做法 |
| --- | --- | --- |
| 复述 | 15 分钟 | 脱离源码解释昨天的模块，并指出一个不确定点 |
| 精读 | 35–45 分钟 | 顺着当日主调用链读代码，遇到依赖先记下职责，再按需展开 |
| 实验 | 20–30 分钟 | 阅读成功与失败测试；运行对应隔离命令，核对断言和结果 |
| 输出 | 10 分钟 | 填一张模块卡，录制或口头完成一分钟讲解 |

时间不足时，完成主入口、关键断言和模块卡；完整套件安排在每周复盘。测试运行较长时，继续阅读已选用例，不把等待时间当成理解完成。

## 如何判断掌握

每个模块都要回答六个问题：

- 它解决什么问题？
- 谁调用它，它又依赖谁？
- 输入和输出是什么？
- 哪些状态保存在内存、数据库、文件或系统凭据库？
- 失败、取消、版本变化时如何处理？
- 这样实现的理由和代价是什么？

仅能列举技术栈算入门；能说明正常路径算理解；能解释失败路径、指出测试断言并比较替代方案，才算达到面试要求。

## 实验与面试的证据

实验使用正式隔离运行器和合成数据，不读取个人配置、真实用户数据库或密钥。原生命令、Windows 沙箱和浏览器实验有环境要求，具体见[实验手册](labs.md#环境问题处理)。

源码实现、合成模型回归、浏览器替身测试、真实 Tauri 安装、第三方 OAuth 和真实供应商任务分别记录。涉及实际供应商的模型请求可能产生费用。

项目文件保存在本机，但推理所需的消息、代码片段和工具结果可能发送给所选供应商。系统凭据库保护的是密钥存储；凭据在请求认证和受控进程运行期间仍有必要的使用边界。

学习记录初始均为未完成。面试中的个人贡献、性能、用户规模和测试成绩使用可核实证据；参考案例需要本人复现或参与处理后，才能写成个人经历。
