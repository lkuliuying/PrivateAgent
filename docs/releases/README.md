# 版本文档

版本目录用于保存某个版本的计划、公开契约、阶段进度和验收检查点。检查点是绑定特定日期或提交的事实快照，后续结论应以更新版本的检查点为准。

| 版本 | 状态 | 入口 |
|---|---|---|
| `v0.3.0` | Runtime 能力冻结的内部检查点 | [开发计划](./v0.3.0/v0.3.0-development-plan.md) · [alpha.2 检查点](./v0.3.0/v0.3.0-alpha.2-checkpoint-20260808.md) |
| `v0.4.0` | UI/UX 改造与 alpha.2 验收资料 | [改造计划](./v0.4.0/v0.4.0-ui-ux-redesign-plan.md) · [alpha.2 检查点](./v0.4.0/v0.4.0-alpha.2-checkpoint-20260808.md) |
| `v0.5.0` | 当前开发主线；B0–B5 已形成 Beta.2 检查点，B6 待完成 | [开发计划](./v0.5.0/v0.5.0-development-plan-20260809.md) · [Beta.2 检查点](./v0.5.0/v0.5.0-beta.2-checkpoint-20260809.md) |

正式发布状态、安装包和变更说明应同时对照仓库根目录的 `CHANGELOG.md` 与实际 Git 标签，不能只根据计划文档判断。
