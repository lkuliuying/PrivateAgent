## 2. 关键决策

1. **审批影响范围自动加载**（W3 退出条件）：待决审批出现即拉取 preview diff
   （基于当前磁盘事实重算，与审批参数哈希无关——v0.5.0 B1 契约），用户无需操作即见
   完整影响；预览失败降级为 previewable=false 的 reason 呈现，不阻断审批操作。
2. **executions 与 transcript 工具条目按「工具名 + 完成顺序」关联**（执行 DTO 无
   tool_call_id，v0.5.0 契约）；同名多次调用的对应关系为顺序近似，输出内容本身
   仍以执行记录为准（事实不虚构）。
3. **@ 上下文为「发现 + 引用附入」**：AgentRunCreateRequest 无独立 context 字段，
   chip 以 `@rel_path` 行附入消息文本（对模型可见、对人可读）；不虚构后端不存在的
   上下文通道。
4. **草稿安全**：localStorage 按 threadId 键隔离（`pa_coding_draft_<threadId>`），
   watch flush:"sync" 即时落盘；载入期间禁写回，避免切线程瞬间把旧草稿写进新键。
5. **输出轮询有界清理**：单一 1.5s 定时器仅在有未完成输出页时存在；finished 即停表，
   组件卸载统一清理（零容忍 §10 资源红线）。
6. **终态用量事实**：run.* 终态 payload 的 tool_call_count/tokens/cost 并入投影 usage
   （此前仅 model.completed 累计，无模型轮次的 run 会显示 0）。
