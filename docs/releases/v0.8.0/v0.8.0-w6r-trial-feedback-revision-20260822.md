## 2. 任务 3：Agent 执行时间线增强（公开事实，不猜测）

- `model/redaction.ts`（新）：呈现层脱敏纯函数——与后端 `_redact_line`
  同语义（bearer/键值凭据）+ URL userinfo 遮蔽 + 命令参数键值遮蔽；
  `redaction.spec.ts` 6 用例。
- `CommandOutput.vue`：命令卡默认呈现**脱敏命令文本**（`execution.output.args`
  持久化公开事实，呈现前 `redactCommandArgs`）、**工作目录范围**（`cwd`）、
  **退出码**（`returncode`，非零失败语义色）、**耗时**（`created_at→completed_at`）；
  stdout/stderr 输出体默认折叠、展开按钮 + 行数提示（长输出不拖垮页面）；
  无公开命令事实时不虚构（只显示状态与错误）。
- `RunTranscript.vue`：工具卡新增**起止时间/耗时**（execution durable 事实）、
  **脱敏命令参数**、**结果摘要**（仅提取 `parsed.summary/verified/profile/file_count`
  有限字段）、**重试序号**（同名执行 ≥2 次的公开事实，单次不虚构徽标）；
  新增 `executions` prop 由工作区透传。
- `CodingThreadWorkspace.vue`：透传 `executions`；`codingRunPreview.ts` 夹具
  对齐后端真实 `output_json` 字段（args/cwd/returncode）并内置凭据形态验证脱敏。
- 边界遵守：事件 payload 不含工具入参（契约红线）——无公开决策摘要处只呈现
  真实计划/动作/验证事实；审批仍以公开 approval 事实为唯一来源；未读取/保存/
  伪造任何隐藏推理。
