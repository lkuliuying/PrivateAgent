## 1. 交付

### 1.1 App.vue 编排迁出（计划 §5.2 的 W4 部分）

- 新增 `features/agent/useLegacyChatSession.ts`（667 行）：旧 chat 视图的**全部**编排
  ——会话/消息/流式状态、planner 判定、plan-then-reply、工具与 Agent run 审批及
  续跑、上下文 5s 轮询、执行结果拉取、候选记忆/收件箱、`?workspace-preview` 注入、
  `dispose()` 卸载清理。行为与迁移前逐行一致（streamSeq/planSeq/contextSeq 竞态
  防护原样保留）。
- `App.vue` 1325 → **790 行**，仅保留：boot/config/sidecar 状态机、视图历史与导航、
  coding 接线（flag/store/预览）、页面动画、全局快捷键、Toast/Confirm/Notification/
  CommandPalette/GlobalSearch 浮层。
- 迁移保真证据：全量 e2e 75/75（含 shell-v2 旧 Agent 流「发送→审批→批准→RAG 来源」
  与「停止即时反馈」用例）+ vitest 213/213 全绿，零行为差异。

### 1.2 API/类型拆分审计（计划 §5.4）

- coding API 零泄漏：`grep` 确认 `api.ts` 未新增任何 coding 段；coding 端点只存在于
  `features/coding/api/*`；`types.ts` 未新增 coding 契约（全部在
  `features/coding/model/contracts.ts|runContracts.ts`）。
- 组件零直接网络：`components/`、`features/` 下 .vue 文件无 `fetch(`/`apiFetch`/
  `invoke(` 调用（W3 的 searchFiles/审批预览/执行输出均经工作区容器或注入发生）。

### 1.3 启发式计划处置（W4 任务 3）

`buildAgentPlan()` **仍有调用方**（旧壳 ChatView v1 + AgentWorkspace/AgentPlanV2 v2
旧 chat 视图——W0 §5.1 回退策略要求保留），不属「已无调用」，按计划 §12 移交
v0.9.0 默认切换后清理。coding 视图零使用（W2 退出条件持续成立，e2e 计划断言全部
来自 plan.* durable 事件/快照）。

### 1.4 bundle 与组件规模基线（W4 任务 5）

- 新增 `scripts/bundle-budget.mjs` + `scripts/bundle-baseline.json`（gzip 字节，
  chunk 归类 index/vendor/tauri/css）：超基线 +5% 警告、**+10% 硬失败**；`--update`
  重定基线须附分布对照（对齐 E-1「不允许以放宽预算掩盖真实回归」原则）。
- `npm run bundle:check` 接入。当前基线（2026-08-22，v0.8.0-alpha.2 后）：
  `css 41.3 kB / index 161.3 kB / tauri 4.7 kB / vendor 110.4 kB`（gzip）。
- 组件规模基线（行数）：App.vue 790、useLegacyChatSession 667、api.ts 2164
  （legacy 聚合层，coding 不依赖）、types.ts 1488（legacy DTO，coding 不依赖）。
