## 1. 新工作台资产清单（v0.9.0 的起点）

- **领域模块**：`apps/desktop/src/features/coding/`（contracts/runContracts/runProjector/
  codingWorkspaceStore/useRunStream/api×4/components×9/dev 夹具×2），桶导出 `index.ts`。
- **启用方式**：`?coding=1|0` / `pa_coding_workbench=1|0`（`config/uiFlags.ts`），
  默认关闭；基于 v2 壳只切 renderer，旧壳/旧页面/数据不受影响。
- **预览夹具**（开发/E2E 复用）：
  - `?coding-preview=`：首页六状态（无项目/无 workspace/Provider 409/sidecar/路径失效/就绪）。
  - `?coding-run-preview=`：任务页十三态（running-early/planning/tools/waiting-approval/
    completed/failed/cancelled/limit-exceeded/patch-preview/command-output/verification/
    conflict/partial-unknown/stress）。
- **测试资产**：e2e `coding-workbench`(12) + `coding-run`(6) + `coding-artifact`(5) +
  `coding-quality`(7) + `coding-w6r`(4，W6-R 新增) + visual 6 例（含 125%/150%）；
  vitest coding 域（含 redaction/命令卡/工具卡/侧栏个人入口）。
- **W6-R 新增资产**：个人工作区六视图（`reminders/inbox/goals/briefings/capture/privacy`，
  viewRegistry daily 组 + 两壳独立主区挂载 + CodingSidebar 入口/徽标）；
  呈现层脱敏 `features/coding/model/redaction.ts`（与后端 `_redact_line` 同语义）。

## 2. 新旧 UI 使用率与错误 telemetry（建议 v0.9.0 立项）

当前无前端 telemetry。建议最小方案（全部本地，不外发）：
- `pa_coding_workbench` 开关读取次数 / coding 视图停留（localStorage 计数即可）；
- `useRunStream` 重连次数、`unknownEventTypes` 命中、`projection.error.code` 分布
  （诊断页聚合呈现）；
- 用于 §4 的默认切换决策提供数据。

## 3. 资源与性能基线

- 长任务预算：**p95 ≤ 60ms / max ≤ 200ms**（E-1 重定，分布对照见
  `performance-resource.spec.ts` 用例注释；重定须附 ≥3 轮分布，不允许以放宽掩盖回归）。
- bundle 基线：`scripts/bundle-baseline.json`（gzip：css 41.3 / index 161.4 /
  tauri 4.7 / vendor 110.4 kB），`npm run bundle:check`（+5% 警告 / +10% 硬失败）。
- 视觉基线：`visual-regression.spec.ts-snapshots/`（v2×5 + coding×6；
  `--update-snapshots` 需人工评审）。
- 资源红线断言：coding-quality「重复 thread 切换净值无增长」+ performance 套件。

## 4. 旧壳、旧 planner 与旧组件依赖清单（默认切换后的清理路径）

v0.9.0 将 coding 壳切为默认（建议顺序）后，可按依赖逐段清理：

| 资产 | 位置 | 前置条件 |
|---|---|---|
| `buildAgentPlan()` 启发式计划 | `models/agentWorkspace.ts` + ChatView/AgentWorkspace/AgentPlanV2 | 旧 chat 视图下线 |
| 旧 chat 编排 | `features/agent/useLegacyChatSession.ts`（W4 迁出体）+ App.vue 旧模板分支 + WorkspaceShell/NavRail/InspectorPanel/ChatView | `?ui=v1` 回退入口按 W0 §5.1 短期保留期满 |
| legacy 聚合 API/类型 | `src/api.ts`（2164 行）/ `src/types.ts`（1488 行）中无 coding 调用方的段 | 随旧视图清理逐段收敛（计划 §5.4 兼容 re-export 策略） |
| `?workspace-preview` 静态注入 | `dev/agentWorkspacePreview.ts` + App.vue boot 分支 | 旧工作台预览下线时一并移除（coding 侧为动态 import） |

**默认切换门槛建议**：内部 dogfood ≥1 个版本周期；回退键常驻（`pa_ui_v2=0`、
`?coding=0`）；「旧 UI 不理解的新数据应安全忽略」已由契约分层保证（coding 数据
只增不改，旧视图不读 coding 契约）。观察后清理建议对齐观察期顺延决策
（v1.0.0-rc.1 前不强制）。

## 5. 已知边界（承接自各里程碑「移交」节）

1. 线程页为单活动 run 视图；历史 run 重访需后端 `session.last_run_id` 写入或
   runs-by-session 列表端点（v0.7.0 交接已知缺口）。
2. executions 与工具条目按「工具名+完成顺序」关联（DTO 无 tool_call_id）；
   并发同名工具多次调用时为顺序近似，压力轮未暴露问题则维持。
3. Artifact 内容级查看（rel_path 读取）需后端内容端点增量。
4. @ 上下文为消息文本附入（`@rel_path`），无独立 context 通道（契约现状）。
5. Markdown 渲染维持 pre-wrap 纯文本（与现行一致）；如需富文本在 v0.9 评估。
6. 输出轮询为 1.5s 定时（单定时器，finished 停表）；如需推送可评估
   executions 输出 SSE 化（后端增量）。
7. （W6-R）旧兼容壳 NavRail 未加六模块图形入口：命令面板关键词/今日页链接可达；
   旧壳清理时一并处置。
8. （W6-R）今日页快捷动作导航后未程序化聚焦目标创建表单；可用路由 `params` 扩展。
9. （W6-R）个人工作区徽标为启动时一次性快照数字（不实时增减）；如需实时可评估
   今日快照轮询或事件化。
10. （W6-R2）对话路径（`ChatRequest` 冻结字段）不支持模型/推理强度/权限模式入参：
    Agent 输入器相应选择为禁用+说明态。若立项扩展（含任何完全访问类契约），
    须单独安全评审、默认关闭并补反向测试。
11. （W6-R2）会话列表无未读计数（后端无未读事实源）；回答复制依赖 webview 剪贴板，
    不可用时降级为可恢复提示。
12. （W6-R3）自动压缩/短期摘要/长期记忆候选的后端自动化未公开：`conversation_summarizer`
    组件默认关闭且无公开状态端点，候选自动生成未实现；UI 按 §6.8 兜底呈现「未就绪」。
    v0.9.0 需补：公开能力位/状态端点、压缩事件投影入 turn、失败重试与去重/取消/隐私策略验证。
13. （W6-R3）ContextRail 在 v2 Agent 页无入口（上下文自动化替代）；组件保留，
    去留待 v0.9.0 决定；文件变更审阅面收敛至审批卡内嵌执行结果。
14. （W6-R3）覆盖安装与启动 smoke 登记为发布流水线项（与 v0.7.0 以来口径一致）。
15. （第四轮决策，计划 §12.1 冻结）以下缺口不在 v0.8.0 补齐，由 v0.9.0 完整承接：
    新建项目与新建对话拆分（项目创建选目录/授权、对话强制绑定）；未指定项目对话的
    「当前用户目录」默认候选（不扩大 trusted path）；工作目录项目创建时冻结 + 后端固定
    Git 检查；会话时间 UTC 存储 + Asia/Shanghai 展示契约；输入器模型控件合并到
    PrivateAgent 入口（删独立 test-model/未配置模块）；上下文用量接入真实 token 窗口/
    输出预算/压缩状态并改为小圆环；「替我批准」真实 workspace 自动批准能力；「完全访问」
    独立 capability（逐会话授权/有效期/撤销/审计，非提权）；点击执行进入 execution 详情视图。
16. （第四轮决策）v0.8.0 发布说明不得宣称「替我批准/完全访问/准确上下文用量/自动压缩/

    拼接百分比），代码终态安装包见下条。
