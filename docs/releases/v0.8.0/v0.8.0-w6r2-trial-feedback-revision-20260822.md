- `AgentWorkspace.vue` 重构为左会话/右工作区：

    新建对话、会话搜索、更新时间与运行状态点；**不复制假列表**。
  - 右区：`SessionHeader`（标题/当前模型/运行状态/上下文入口）→
    `TurnTranscript`（主时间线独立滚动，正文可读宽度 880px 居中）→
    `AgentComposer`（固定底部，高度变化不遮挡末条消息）。
  - 窄窗口（<1280）会话栏折叠为浮标 + 抽屉；选择后自动收起。
  - 草稿按会话保存（`draftBySession`），切换/重命名不串线不重置。

## 3. 任务 3/4：模型、推理强度与三档权限绑定真实契约（计划 §6.7 权限表）

- `AgentComposer` + `model/agentCapabilities.ts`（纯函数，可单测）：
  - 模型/推理强度：对话路径（`ChatRequest` 冻结字段）不接受相应入参 →
    选择器**禁用并说明**，不静默改用默认值（零容忍：不伪造选择）。
  - 总是询问：对话运行时真实语义（写入/命令前审批流），唯一可选。
  - 替我批准：需工作区 + 安全命令档案契约，对话路径未开放 → 禁用 + 真实原因。
  - 完全访问：仅当 `/capabilities` 显式返回独立支持位才可选；当前
    `RuntimeCapabilities` 无该字段 → 「当前不可用」。未把 `workspace`
    伪装成完全访问，未发送后端拒绝的模式，未新增后端契约。

## 4. 任务 5：逐轮 turn 分组与回答复制（计划 §4.4 逐轮结构）

- `model/agentTurns.ts`（typed projector，纯函数）：每条用户消息创建稳定
  turn（键 = 用户消息 clientKey/id）；同轮工具/审批/中间公开消息与最终回答
  归入该分组；归属只依赖消息边界，不按时间/文案猜测。
- 公开思考摘要边界：无公开摘要时仅呈现「正在分析/正在执行工具/等待审批」
  等真实状态标签（由审批/工具/流式事实推导），不生成解释性内容冒充思考。
- `TurnTranscript`：稳定 turn 容器（断线/停止/重水合后按消息事实重组可复查）；
  完成后呈现「复制回答」。
- `model/copyAnswerText.ts`：复制内容 = 该轮可见最终回答正文（保留换行）；
  不混入按钮文案/过程/隐藏 DOM；成功只提示「回答已复制」，失败/剪贴板不可用
  给出可恢复指引；通知与提示一律不含回答正文。
