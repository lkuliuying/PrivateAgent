### 1.2 改造

- `CodingThreadWorkspace.vue`：W1 占位升级为完整组装（Header+Transcript+PlanPopover+极简输入器）；审批详情经 `GET /agent-runs/{id}/approvals` 补全（事件只带 approval_id，风险/能力/过期只在审批 API）；输入器 Enter 发送创建 run（`POST /agent-runs` 带 session/project/workspace），执行中显示停止；W3 由 CodingComposer 取代。
- `App.vue`：`CodingThreadWorkspace` 以 `:key=threadId` 挂载——**切换任务即卸载组件 = run 流/定时器整体清理**（零容忍 §10 的结构性保证）。
- `api/modelProfiles.ts`：非数组响应体按可恢复错误处理（不击穿 bootstrap）。

## 2. 关键事实与决策

1. **coding run 无 token 级流**（v0.7.0 契约）：`POST /agent-runs` 不开 output_queue，
   全文只在 `run.completed.payload.output` 与快照 `output`；`model.completed` 仅 usage/延迟
   元数据。RunTranscript 因此呈现「轮次摘要 + 终态全文」，与计划 §2「不展示隐藏推理，
   只展示公开计划、动作、验证和结果」一致。
2. **投影写时复制**：applyRunFrame 为纯突变函数，`useRunStream.mutate` 在 draft 上应用后
   以**新引用**发布到 shallowRef——否则 runStatus 等 computed 链不失效（实现期实测教训：
   状态徽标停在「执行中」而 transcript 偶发更新）。
3. **重连纠偏顺序**（计划 §5.3）：快照（durable 事实，含 plan/artifacts）→ 以本地游标
   重放 events 缺口 → `after_sequence=游标` 续读 SSE。旧快照（`last_event_sequence < 游标`）
   不回退已应用事实；终态快照直接收敛不再开流。
4. **审批闭环**：`tool.approval_required` 事件带 approval_id（与 checkpoint 原子落库）；
   审批卡字段（risk_level/required_capabilities/expires_at）取自 approvals API；批准 →
   服务端 resume 续跑（SSE 续流收 approval_resolved/后续事件）；拒绝 → `cancel_waiting_approval`
   → run cancelled（error_code=approval_rejected）。前端不本地猜测状态，全部由事件/快照收敛。
5. **`run.terminal` 合成帧**：仅用于提前收敛与关流判定；不携带输出，durable `run.completed`
   未到时不虚构文本。
6. **run.terminal 之外的清理语义**：AbortController + 重连定时器在 detach（thread 切换/卸载/
   scope dispose）统一释放；迟到流帧经世代令牌丢弃（单测覆盖）。

## 6. 已知边界与 W3 移交

1. 输入器为极简形态（Enter 发送，权限默认后端 readonly）；W3 交付 CodingComposer
   （@上下文、/ 命令、权限三模式、模型 profile、reasoning_effort 选择器）。
2. 工具卡为摘要行；工具执行结果与命令流式输出（`GET .../executions/{id}/output`）、
   PatchSet Diff Artifact、测试报告为 W3。
3. 线程页当前呈现「单活动 run」；历史 run 重访需要后端 `session.last_run_id` 写入或
   runs 列表端点（v0.7.0 交接已知缺口，未在本版擅自补造）。
4. 侧栏 run 活动徽标（运行中/等待审批/未读）待 W3 随 ContextDrawer 一起评估数据源
   （pending-approvals by session 已可用）。
5. 输出为 pre-wrap 纯文本（与现行消息渲染一致）；Markdown 渲染未在计划范围，如需在 W5 视觉轮评估。
