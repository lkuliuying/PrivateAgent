## 5. 归属与时间迁移报告

- 对象层级 `Project → Workspace → Conversation → Run` 冻结（H0 §4.1）；
  coding 会话强制 `project_id+workspace_id`；legacy/unbound 仅经
  `POST /sessions/{id}/bind-project` 显式迁移（`session_project_bindings`
  审计表，迁移 0031）；无批量绑定端点（契约测试反向断言）。
- 「当前用户目录」候选：`/projects/user-home` 幂等创建、**不写
  trusted_paths**；`/projects/{id}/authorize-scope` 显式确认后才建立信任。
- 时间：DB 保持 naive UTC 事实；API 统一 `format_rfc3339_utc`（带 `Z`）；
  前端 `services/timeDisplay.ts` 固定 `Asia/Shanghai` 24 小时制；
  `history.py` 消息写入从 `func.now()` 迁移到 `utcnow()`（消除会话时区漂移）。
  历史数据不改写，消息先后顺序不变。

## 6. 三档权限 / 上下文 / 公开执行链报告

**三档权限**（`confirm`/`workspace`/`full_access`）：
- 能力位 `coding_workspace_auto_approve` 与 `coding_full_access_supported`
  独立声明（非别名，契约测试断言）；
- `full_access` 授予表（迁移 0031）：显式二次确认、4 小时有效期（可配）、
  撤销端点、到期/重启自动回收（启动/退出钩子）；
- 执行层每次工具调用前重验授予（竞态安全）；硬边界（网络外发/外部 MCP）
  永不自动批准；降级遥测 `permission_downgrade`（低基数原因）；
- 输入器内 `full_access` 授予状态与即时撤销入口（显示有效期，一键撤销，
  撤销后回落 `confirm`）；
- 反向安全测试 6 用例（`test_v090_h5_security.py`）。

**上下文 budget/压缩**：
- `GET /sessions/{id}/context-budget` typed budget（used/max/reserved/
  percent/source/compaction_state）；
- 用量仅来自 provider usage（`source=provider_usage`），不可用如实声明
  （无字符数伪造）；百分比域 0..100 封顶；
- 阈值压缩：确定性保留最近消息 + `context.compaction_*` durable 事件；
  压缩后仍超限 → 409 `budget_exceeded` 停止新执行（不静默截断）；
- 圆环 `ContextUsageRing`：aria-label/文本替代/非颜色标记，
  hover/keyboard focus 弹层。

**公开执行链隐私审查**：
- `decision.summary` payload 键集冻结（7 键），投影层拒绝未知键；
  仅从公开事实派生（用户目标/模型公开工具决策），无隐藏 CoT 读取/持久化；
- `GET /agent-runs/{id}/execution-detail` 聚合端点：参数脱敏
  （敏感键/绝对路径占位），命令/审批/验证可追溯；
- 遥测全程低基数计数，无代码/路径/命令正文。

3. 上下文压缩为确定性保留策略（非 LLM 摘要）；`conversation_summarizer`
   启用后需补压缩事件对接；
4. 共享测试库顺序敏感用例在极高负载下存在瞬态抖动（复跑不复现，已记录）；

   视觉随设计系统迭代）。

**支持范围**：Windows（本版本）；macOS/Linux 正式发布不在本版本范围

## 8. H1-B/H1-C 实机试用纠偏（2026-08-23 增补）

依据计划第二、三轮实机试用反馈（§1.11-12/§5.6/§5.7），在内部开发完成版
基础上增量纠偏，详见 [v0.9.0-h1bc-trial-correction-20260823.md](./v0.9.0-h1bc-trial-correction-20260823.md)：

- **动手主链**：内置只读诊断 profile（`where.exe mysql` / `mysql --version` /
  `where.exe mysqld` / `sc.exe query <MySQL 家族服务>`，固定 argv、safe、
  零网络）；可执行意图识别 → 注入 `min_tool_executions` 证据门槛（无执行
  证据的“完成”宣称失败关闭）；创建失败阻塞卡片 + 恢复入口 + 草稿回填。
- **安装版能力位**：桌面 sidecar 注入 14 个 v0.9.0 能力位（产品默认
  `true`，显式 `false` 精确回退）；`/capabilities` 新增审计/撤销/诊断命令面
  独立声明；权限选择按会话持久化；上下文圆环新增来源/最近更新/焦点重探测。
- **红线不变**：默认权限模式仍 `confirm`；能力位是可用性声明不是权限授予；
  不读取/不展示隐藏 chain-of-thought；诊断命令精确 argv 不可拼接。
- 移交 v1.0 观察矩阵增补：可执行意图路由矩阵（信息问答/检查本机/查看项目/
  运行测试/修改文件）与 Windows MySQL 检查矩阵（PATH 命中/未配置/仅服务/
  未安装/拒绝/失败/超时/取消/中断恢复）随发布流水线安装版验收执行。
