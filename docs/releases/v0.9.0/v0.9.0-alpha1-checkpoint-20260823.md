## 3. 零容忍项自查（计划 §11）

- 新安装默认权限 = `confirm`（非 workspace/full_access）✅
- 升级不丢数据、不隐式绑定（仅 `bind-project` 显式，无批量端点）✅
- full_access 不绕过授权/撤销/到期；凭据/远程外发硬边界保留 ✅
- 上下文圆环数值来自后端 typed budget；不可用如实呈现，无字符数伪造 ✅
- 执行详情只含公开决策链（`decision.summary` 键集冻结），不读取/展示隐藏 CoT ✅
- telemetry 仅低基数计数（`permission_downgrade`/`full_access_grant`/`context_budget_poll`），无路径/命令/代码正文 ✅
