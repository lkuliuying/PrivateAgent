## 1. H4 · 搜索、管理与旧工作区整合（达成）

| 交付 | 落点 |
|---|---|
| 会话重命名 | `PATCH /sessions/{id}/title`（有界、去空白） |
| 会话归档/恢复 | `POST /sessions/{id}/archive`、`/unarchive`（软删除，默认列表不含，不物理删除） |
| 置顶/取消置顶 | `POST /sessions/{id}/pin`、`/unpin` |
| 最近任务 | `GET /sessions/recent`（置顶优先 → 更新时间倒序，不含已归档） |
| 会话搜索 | `GET /sessions/search`（标题匹配，不含已归档，空关键词 422） |
| 项目搜索 | `GET /projects/search`（名称匹配，含有界） |
| 列表默认排除已归档 | `SessionRepository.list(include_archived=False)` |
| 前端呈现 | 侧栏线程行置顶/重命名/归档动作、「最近任务」区（置顶优先）、「更多工作区」未绑定 legacy 会话次级入口（逐条显式绑定迁移）；`threads.ts` 管理 API（`renameThread`/`setThreadArchived`/`setThreadPinned`/`fetchRecentThreads`/`searchThreads`/`fetchUnboundLegacyThreads`） |

**退出条件核对**：归档/重命名/置顶/最近任务前后端契约齐全（后端端点 + 侧栏线程行动作/最近任务区/更多工作区次级入口）；旧会话可读可管理可迁移，软删除不丢数据。

## 2. H5 · 可靠性与安全（三档权限反向安全，达成）

| 反向安全用例 | 结果 |
|---|---|
| full_access 硬边界：NETWORK_FETCH / EXTERNAL_MCP 永不自动批准 | ✅ |
| 授予中途撤销 → 下一调用降级为逐次审批（竞态安全） | ✅ |

| 上下文预算域防护（封顶 100、不可用无百分比、无负数/无 >100） | ✅ |
