### 1.2 H0 退出条件核对

- 默认值不隐式扩大权限：全部新 flag 默认 False；API 缺省权限仍最小（`readonly`）；
  产品默认 `confirm` 由前端显式声明（§3.1）。
- 回退原因可解释：`coding_ui_fallback`/`permission_downgrade` 低基数遥测就位。
- 无空归属/猜测绑定：coding 会话强制 `project_id+workspace_id`；绑定唯一显式入口。
- 权限与上下文 UI 不依赖占位常量：capability 声明位 + 真实计量 DTO 冻结。

## 2. H1 · 新 UI 默认与首启流程（达成）

### 2.1 后端

- **时间契约**：`/sessions`、`/sessions/{id}/messages`、workspaces、run/事件
  时间统一带 `Z` 的 RFC 3339 UTC（`field_serializer`/`_timestamp`）；历史值不改写，
  只补时区语义（计划 §3.2）。
- **会话绑定**：`POST /sessions/{id}/bind-project`（唯一入口；重复绑定 409
  `session_bind_conflict`；归属校验同创建链；审计行入 `session_project_bindings`；
  无批量端点并有契约测试断言）。
- **当前用户目录候选**：`GET /projects/user-home-candidate`、
  `POST /projects/user-home`（幂等，**不写 trusted_paths**，响应不含绝对路径）、
  `POST /projects/{id}/authorize-scope`（显式确认才建立信任）。
- **升级契约**：`core/v090_upgrade.py` 启动幂等补建全部 active 项目的 root
  workspace + 进程重启回收 full_access 授予；退出回收接入 lifespan（失败只记录不阻断）。

### 2.2 前端

- **默认切换**：`config/uiFlags.ts` `DEFAULT_CODING_WORKBENCH=true`；
  显式回退键常驻（`?coding=0`/`pa_coding_workbench=0`）；启动后核对
  `/capabilities.coding_agent_ui_enabled`，关闭且非显式选择时回落旧 UI
  （App.vue，本地计数 `codingUiTelemetry`，不外发）。
- **新建项目/新建对话拆分**（计划 §5.1）：
  - 侧栏主按钮「新建任务」→「新建对话」（沿用首页输入器主链）；
    新增独立「新建项目」动作（`NewProjectDialog`：选择目录+授权 /
    用户目录候选+范围确认两步）。
  - 首页空态提供「新建项目」与「打开项目页」；文案全面对话化
    （「开始一个新对话」）。
  - 候选预创建不自动授权：授权范围确认为显式第二步骤（可「暂不授权」）。
- **Asia/Shanghai 显示服务**：`services/timeDisplay.ts`（24 小时制、自然日分组
  按产品时区、相对时间）；替换 ConversationList/CodingSidebar 两套重复实现；
  单测覆盖跨日/上海零点/非法输入。
- **产品默认权限**：CodingComposer 默认 `confirm`（计划 §3.1；后端缺省最小权限不变）。
- **本地遥测**：视图进入/回退原因 localStorage 计数（交接包 §2 最小方案）。

### 2.3 H1 退出条件核对

- 新用户首启可完成首个任务：默认进入 Coding Home → 新建项目（选目录授权或
  用户目录候选+范围确认）→ 新建对话 → 提交执行（e2e smoke 新用例覆盖默认切换与回退）。
- 旧用户升级不丢失入口或数据：旧会话保持 `kind=legacy`，经「显式绑定」迁移；
  启动补建 root workspace；`?ui=v1`/`?coding=0` 回退保留（e2e 覆盖）。
- 新对话均有稳定项目/workspace：后端创建链不变；项目创建失败不留半绑定
  （后端同事务 + 候选两步确认）；无猜测绑定（契约测试断言无批量端点）。
