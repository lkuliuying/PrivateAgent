## 3. 测试覆盖（计划第 9 节矩阵，E3 行）

- 单元/契约：kind 枚举冻结；输入校验（kind/rel_path 绝对路径、`..`、反斜杠、盘符/content_sha256/metadata 超限）；完成条件三扩展（must_pass_profiles 成功/未执行/失败、no_pending previewed 阻塞、final_git_diff 四种事实组合 + 非 git 失败关闭）。
- 集成：服务层 create/list 分页；API POST 201/GET 分页/422 artifact_invalid/404；投影全链（propose→apply 即时投影 + 终态重建 + final_report 来源引用与 completion_satisfied）。
- 故障/回退：flag 关闭（`PA_CODING_ARTIFACTS_ENABLED`）时 propose 与 rebuild_terminal 全部 no-op，零 Artifact 写入；非终态 status 不重建；API 422 错误映射。

结果：`tests/test_v070_artifacts.py` **15 passed**；v0.7.0 全套（contracts/commands/patchset/artifacts + test_public_contracts）**88 passed / 2 xfailed**；Agent run 回归（runs_api/patch_workflow/runtime/verification）**49 passed / 1 skipped**，零失败。

## 4. 实现要点与修复记录

- **rebuild_terminal 命令投影幂等缺口（测试捕获）**：文档声明按来源指纹幂等，但 `_project_command` 未去重，重复调用产生重复 command_result/报告引用；修复为终态重建前读取已投影 `source_execution_id` 集合（覆盖 command_result/test/lint/build_report 四类），命中即跳过，与 patch_set/final_report 去重语义一致。
- **投影失败不影响执行事实**：`_create`/`_list_patch_sets` 全部 try/except 兜底（失败仅记日志），Artifact 是 execution 事实的展示投影，非事实源。
- **final_report 只生成一次**：按 kind 查重后创建；metadata 含 run_id/status/completion_satisfied/completion_conditions/step_ids/tool_names/artifacts 引用（截断 32 条），不内嵌完整命令输出或文件内容。
- **Git Diff 判定边界**：`final_git_diff` 非 any 时才读 workspace Git 快照；非 git 目录 `git_diff_empty=None`，nonempty/empty 条件按契约失败关闭（不猜测）。
- **API 测试隔离**：run 后台任务注入立即完成模型（沿用 E2 约定）；durable 事件/投影写入经独立 session，断言走重绑 factory 新建 session（MySQL REPEATABLE READ）。

## 5. 安全契约核对（计划第 4/11 节）

- 投影与 Artifact 只保存脱敏、有界、可展示内容；`rel_path` 校验拒绝绝对路径/反斜杠/上级引用；原始 execution 仍是审计事实源。
- 完成条件全部基于 durable 事实（executions/patch_sets/Git 快照）求值，模型不能自行降低或宣称满足（零容忍「模型绕过完成条件」无入口）。
- `final_git_diff` 不可判定即失败关闭，不通过模型文本声明验证成功。

## 6. 可回退性（计划第 10 节）

- `PA_CODING_ARTIFACTS_ENABLED` 默认关闭：关闭时投影全链路 no-op，不删除 execution 事实，也不影响 PatchSet/命令主链。
- schema 全部 additive：kind ENUM、completion_conditions 字段、分页参数均向后兼容，无破坏性 downgrade。
- 应用回退保留新表（coding_patch_sets/agent_run_artifacts 新 kind），与 E0 §8 一致。
