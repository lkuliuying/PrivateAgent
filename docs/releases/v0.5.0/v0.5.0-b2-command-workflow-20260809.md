## 1. 交付内容

### 1.1 可信执行器（`core/command_workflow.py`）

`run_whitelisted_command` 已包装为 versioned `ToolSpec`（B0 冻结契约），执行链路：

1. **白名单合并**：全局默认前缀（`is_whitelisted_command`）∪ 项目 `command_profile`
   前缀（`project_command_profiles` 预授权）；两者都不匹配 → `PermissionError_`
   拒绝；参数数组逐项拒绝 shell 控制符；字符串命令由输入 Schema 拒绝；
2. **环境 allowlist**：只继承固定变量（PATH/SystemRoot/TEMP 等，大小写不敏感
   casefold 匹配），显式清除代理/凭据/无关继承变量；
3. **Windows Job Object**（`KILL_ON_JOB_CLOSE`）：子进程一启动即挂入 job；
   超时/取消/异常路径 `TerminateJobObject` 终止整棵树；终止后查询 job 内
   `ActiveProcesses` 作为清理证据（`processes_remaining`）；POSIX 分支保留
   进程组实现（正式支持面为 Windows）；
4. **有界流式输出**：两个 reader 持续 drain（防管道阻塞），单行 ≤8KB、
   持久化 ≤5000 行、汇总 ≤30KB、超限标记；写入前按 secret 文本模式脱敏；
   行以换行拼接（防脱敏正则吞并后续内容）；
5. **流式持久化**：新表 `tool_execution_output`（additive 0024，`execution_id+seq`
   唯一）；executor 通过 `current_execution_id()` contextvar（dispatcher claim 后
   设置，执行结束复位）绑定 execution 写行；失败静默降级不阻断命令；
6. **取消语义**：CancellationToken 触发 → 杀树 → 证据写入 execution 记录
   （`error_message` 含残留数）；任务级取消原样传播；
7. **不可重放**：`non_idempotent`——崩溃后 unknown execution 拒绝自动重跑。

## 3. 环境说明与已知边界

- **Windows `python` 解析**：本机 CreateProcess 的 App Paths / PATH 解析把裸
  `python` 指向系统解释器；测试通过 venv Scripts 前置 PATH 模拟安装版环境，
  以 `pytest` 可执行文件验证白名单命令；生产安装版由部署环境保证 PATH。
- **命令验证器边界**：Shell+CodeCommand 组合验证器要求输出含成功标记
  （passed/ok/built 等）——项目自定义 profile 命令若无标记会被验证失败
  （安全侧失败关闭）；已在 B0 文档 §4.2 记录。
- **环境变量 allowlist 大小写**：Windows 环境变量名大小写不敏感但保留原始
  大小写（部分环境为全大写 SYSTEMROOT），allowlist 按 casefold 匹配。
- **流式持久化尽力而为**：DB 写失败时静默降级（execution 最终结果仍持久化）。
