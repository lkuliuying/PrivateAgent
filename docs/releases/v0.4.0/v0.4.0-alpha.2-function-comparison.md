# 0.4.0-alpha.2 全生产页面功能对照表

> 检查点：`0.4.0-alpha.2`；对照基线：`0.3.0-alpha.2` 功能清单
> 用途：D4 退出条件「功能清单无丢失，全部生产页面完成迁移」的逐页证据
> 自动化证据：`apps/desktop/e2e/`（pages-smoke / shell-v2 / smoke / animation / visual-regression / performance-resource / accessibility）+ `src/**/*.spec.ts`

## 覆盖说明

- **空态**：pages-smoke 以空数据 mock 逐页验证主体渲染（空态可见）；
- **错误态**：后端断开（health 503）验证；页内错误条由既有组件逻辑覆盖（E2E「后端断开提示」）；
- **加载态**：首屏加载由各页 loading 标志实现，pages-smoke 的 networkidle 等待与骨架回归快照覆盖；
- **键盘**：pages-smoke 每页 Tab 可达断言 + accessibility spec（axe + focus-visible）；
- **窄窗口**：1280 无横向溢出断言（pages-smoke）+ 960/1440/1920 Today/KB 布局 E2E + 视觉回归；
- **权限态**：文件授权/审批权限由 Agent 审批卡与 Inspector Files 授权路径承载（ApprovalCardV2/ContextRail 单测 + shell-v2 E2E）。
