### 2.2 e2e 性能用例历史失败（K2，非回归，最终门禁通过）

`performance-resource.spec.ts:205`「页面切换与主要操作：无 50ms 级无必要长任务」曾在流水线负载下 p95=51-61ms（预算 50ms）。

**非回归证据链（完整）：**

1. `git diff 9250da6..578db27 -- apps/desktop`：生产运行时**零变化**——仅版本号 bump、`types.ts` 纯类型声明、`api.ts` 新增未被 UI 调用的函数、`runProjector.ts` 新模块（无生产引用）、dev fixture（不进生产产物）。
2. **基线对照实验**：对 rc.4 冻结提交 `9250da6` 建 git worktree，同一机器、同一时间窗、同一依赖运行同一用例 → **同样失败**（52ms / 53ms），与 v0.6.0 候选代码无关。
3. 该用例自 0.4.0 起即处于预算临界（rc.4 检查点记录：套件内 51-57ms 临界、单独跑稳定 50ms），当前机器存在后台负载（douyin 1.4GB、Ollama、IDE 等）导致基线漂移。

处置：记录为已知问题 K2（环境漂移，附对照证据），不修改性能预算或测试逻辑；不构成 P0/P1。**最终 release-check-full（绑定最终 HEAD，见第 8 节）该用例通过（e2e 52/52）**，印证环境漂移判定，K2 记录保留备查。
