## 5. 已知问题与回退说明

1. **LLM 需要显式 project_id 上下文**：qwen2.5-14b 在工具参数中会编造 project_id（如 123456789），导致项目查询失败。Beta.1 阶段由工作流提示注入真实值；B5 的 ContextBuilder 上下文注入应把"当前授权项目"作为系统事实。回退：不使用 patch/命令工具即可规避（只读工具不受影响）。
2. **Windows 符号链接 E2E skip**：本机无 Developer Mode/管理员权限（WinError 1314），真实链接逃逸用例在 CI/权限环境执行；拒绝逻辑已由 monkeypatch 注入测试覆盖。
3. **命令验证器严格要求成功标记**：项目自定义 profile 命令输出若无 passed/ok 等标记会被验证失败（安全侧失败关闭），已记录于 B0 文档 §4.2。
4. **E2E 环境抖动**：视觉回归与性能测试（p95≤50ms）在后台负载下偶发失败，单独复跑通过；非代码缺陷。
5. **回退说明**：全部新能力由独立 flag 控制，单 flag 关闭无需数据库 downgrade；schema `0024` 为 additive，旧版应用可读取原表（0023/0024 均为新增表/列）。
